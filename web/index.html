Proposed Methodology & Fusion Flow

A clinician rarely diagnoses from a single source. Medical images are interpreted jointly with symptoms, vitals, and laboratory values. This system introduces intermediate feature fusion where an image encoder extracts \(z_i = f_\theta(x_i)\) using DenseNet-121, and a clinical MLP encoder extracts \(z_c = g_\phi(c_i)\).

Intermediate Fusion: z_f = z_i || z_c
Classification Head: y_hat = h_psi(z_f) in [0, 1]

The concatenated embedding \(z_f\) allows both modalities to develop specialized feature representations prior to diagnostic synthesis.

Missing Clinical Data Handling & XAI

In real-world clinical triage, laboratory values are frequently unavailable or delayed. To model incomplete records, a binary mask \(m\) flags observed features, and missing features are imputed using training set statistics:

c_tilde = m * c + (1 - m) * c_imp
Network Clinical Input = [c_tilde, m]

Explanations are provided via dual modalities: Grad-CAM generates spatial heatmaps of influential thoracic features, while Integrated Gradients measures feature-attribution values for every clinical variable.
